🚦 3 Real-World Gate Scenarios

1. 🟢 Arriving Vehicle (Green Trigger)
Vehicle drives inside and hits the green line. System confirms ENTERING, auto-assigns next parking bay, stamps entry time, and opens barrier.
2. 🔴 Departing Vehicle (Red Trigger)
Vehicle leaves bay and reaches the outer gate red line. System checks database: if recorded INSIDE, stamps exit time and frees the parking bay.
3. 🛡️ Street Traffic (False Alarm Filter)
Outside cars passing on the road brush past the red line. System checks DB: if NOT INSIDE, it completely ignores the event with 0 false records.
